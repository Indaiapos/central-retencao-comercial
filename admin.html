Configurar acesso

Isso guarda um token do GitHub criptografado com a senha que você escolher num arquivo público do repositório (admin-key.json) — sem a senha, esse arquivo não serve para nada. A partir de agora, só a senha será necessária para entrar.

Como gerar o token (uma vez só): GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em "Repository access" escolha Only select repositories → Indaiapos/central-retencao-comercial. Em "Permissions" → Contents → Read and write. Nenhuma outra permissão é necessária.

Use uma senha longa e única (16+ caracteres) — o arquivo criptografado é público, então a força da senha é a única proteção. Ninguém, incluindo quem configurou o site, consegue recuperar o token sem essa senha.
