Entrar no admin

Esta página edita precos.json direto no GitHub. Você precisa de um token pessoal (PAT) com acesso de escrita só a este repositório.

Como gerar (uma vez só): GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em "Repository access" escolha Only select repositories → Indaiapos/central-retencao-comercial. Em "Permissions" → Contents → Read and write. Nenhuma outra permissão é necessária.

O token fica salvo só neste navegador (não é enviado para nenhum lugar além do próprio GitHub). Para sair, use "Esquecer token" no topo depois de entrar.
